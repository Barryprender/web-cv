# Architecture decision records

Decisions that were contested, that closed off an alternative, or that a new
reader would otherwise have to reconstruct from source comments. Most reasoning
belongs in `README.md` or `docs/technical-documentation.md`; what lands here is
what needs a status and a date attached, because it can be reversed or
superseded.

Numbers are never reused. A record is never deleted — a superseded one keeps
its text and gains a status pointing at its replacement, because the wrong
turns are half the value.
